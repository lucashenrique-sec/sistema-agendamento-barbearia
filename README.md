# Sistema de Agendamento Online para Barbearia

## Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema de agendamento online para uma barbearia, facilitando a organização dos horários e o atendimento aos clientes.

A ideia surgiu após uma entrevista com um barbeiro autônomo, que atualmente realiza seus agendamentos pelo WhatsApp e precisa interromper seus serviços para responder aos clientes.

## Problema identificado

O principal problema é a dificuldade de organizar os agendamentos enquanto o barbeiro está atendendo.

Além disso, os cancelamentos podem gerar horários vagos e tempo ocioso, pois é necessário entrar em contato com outros clientes para tentar antecipar os atendimentos.

## Objetivo do sistema

Criar uma aplicação simples que permita aos clientes consultar os horários disponíveis e realizar agendamentos, ajudando o barbeiro a organizar melhor sua rotina.

## Funcionalidades planejadas

- Cadastro de clientes.
- Cadastro dos serviços de cabelo e barba.
- Consulta de horários disponíveis.
- Agendamento de serviços.
- Cancelamento de agendamentos.
- Confirmação dos horários agendados.
